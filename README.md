# SeismoScope 🌍

Scientific earthquake analytics and machine learning project focused on 72,583 global seismic events from 2015–2024.

## Overview
The portfolio describes a desktop system for earthquake magnitude classification, interactive exploration, and explainable predictions.

## Technology
- Python 3.12
- PySide6 / Qt
- scikit-learn and XGBoost
- SHAP explainability
